# VikasVerse — Learn. Connect. Grow.

Responsive student career + community prototype based on the supplied UI reference and specification.

## Run locally
1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Create a virtual environment (recommended): `python -m venv .venv`
4. Activate it, then run: `pip install -r requirements.txt`
5. Start the app: `python app.py`
6. Open http://127.0.0.1:5000

## Included
- HTML, CSS and vanilla JavaScript frontend
- Python Flask REST API
- Dashboard, social feed, opportunities, SkillPath AI demo, ScamSense rule-based demo, network, learning hub, saved/application tracker, profile editor and settings
- Responsive desktop/tablet/mobile layout

## Important prototype notes
- Listings, people, deadlines and match scores are sample/demo data.
- SkillPath recommendations are deterministic examples, not generated by a live AI model.
- ScamSense uses simple keyword rules. It does not verify employers, URLs, or whether an opportunity is fraudulent.
- The API uses in-memory demo state; restarting the server resets saved items, posts and application statuses.
- Before production: add authentication, database persistence, input validation/rate limiting, CSRF protection where relevant, secure deployment settings, and real source-verification/AI services.
